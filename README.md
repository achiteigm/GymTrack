# GymTrack PWA

Aplicatie web progresiva pentru iPhone, fara App Store.

## Ce include
- 3 zile de antrenament, conform programului furnizat.
- Seturi bifabile.
- Greutate si repetari pentru fiecare set.
- Salvare locala in browser.
- Istoric sesiuni.
- Ecran de progres si ultima performanta.
- Functionare offline dupa prima incarcare.
- Interfata optimizata pentru iPhone si dark mode.
- Demonstratii animate vectoriale, fara dependente externe.

## Instalare pe iPhone
1. Publica folderul pe un hosting HTTPS (de exemplu GitHub Pages, Cloudflare Pages, Netlify sau Vercel).
2. Deschide URL-ul in Safari.
3. Partajare -> Adauga la ecranul principal.
4. Deschide GymTrack ca o aplicatie.

## Important
localStorage este local pe dispozitiv si in browserul respectiv. Daca Safari sterge datele site-ului sau utilizatoarea schimba dispozitivul/browserul, istoricul nu se transfera automat.

Pentru o versiune urmatoare se poate adauga export/import JSON sau sincronizare cloud.
